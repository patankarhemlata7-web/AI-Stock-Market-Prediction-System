

# AI Stock Market Prediction System

## 📊 Project Overview

The **AI Stock Market Prediction System** is a Python-based machine learning and data analytics project designed to analyze historical stock market data and predict future stock prices.

The system combines **Python, SQL, MySQL, FastAPI, Streamlit, and Machine Learning** to provide stock analysis, visualization, and prediction through an interactive application.

---

## 🎯 Project Objectives

- Analyze historical stock market data
- Clean and preprocess stock market data
- Predict future stock prices using Machine Learning
- Compare different machine learning models
- Store and manage stock data using MySQL
- Analyze stock price and trading trends
- Present results through an interactive dashboard

## 📁 Dataset Overview

The project uses historical stock market data for analysis and prediction.

### Key Data Fields

- Open Price
- High Price
- Low Price
- Close Price
- Trading Volume
- P/E Ratio
- Debt-to-Equity Ratio

The data is cleaned, preprocessed, and transformed before applying machine learning models.

---

## 🤖 Machine Learning Models

### 1. Linear Regression

Used to understand the relationship between input features and stock prices and generate predictions.

### 2. Random Forest

Uses multiple decision trees to handle complex relationships in stock market data and improve prediction performance.

### 3. XGBoost

A powerful boosting algorithm that combines multiple decision trees to generate accurate predictions.

The three models are used to compare prediction performance.

---

## 📈 Dashboard Analysis

The application provides analysis through multiple sections:

### 1. Stock Market Dashboard

Provides an overview of stock market information and important indicators.

### 2. Stock Charts

Displays historical stock price movements and trends using interactive charts.

### 3. Dataset Analysis

Allows users to view and analyze the processed stock market dataset.

### 4. Stock Price Prediction

Predicts future stock prices using **Linear Regression, Random Forest, and XGBoost**.

### 5. Profit & Loss Analysis

Provides portfolio-related information and helps analyze profit and loss.
